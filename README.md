# Dataset Documentation

## 1. Nguồn dữ liệu (URL)
- Kho tham khảo: https://github.com/cszn/FFDNet
- Bộ dữ liệu: **BSD68** (nhóm ảnh test / CBSD68) và **Set12**

## 2. Số lượng ảnh
- **BSD68:** 68 ảnh
- **Set12:** 12 ảnh
- Chi tiết từng file xem tại `data/manifest.csv`

## 3. Kích thước ảnh
- Các ảnh test trong danh sách có kích thước thực tế như `321x481` hoặc `481x321` (xem chi tiết từng dòng trong `data/manifest.csv`).
